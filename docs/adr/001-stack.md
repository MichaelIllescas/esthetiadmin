# ADR 001 — Stack: Angular + Spring Boot + MySQL + Docker

**Estado:** aceptada · 2026-09-25

## Contexto
Desarrollador único con plazo de 2 semanas. Ya trabaja con este stack.

## Decisión
Frontend en Angular, backend en Spring Boot, base de datos MySQL, contenedores con Docker.

## Consecuencias
- Sin curva de aprendizaje: todo el tiempo va a funcionalidad.
- Backend y base de datos se despliegan como contenedores.
